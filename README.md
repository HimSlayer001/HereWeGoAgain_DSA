# NeetCode Solutions

A curated collection of my solutions to problems from **NeetCode**, implemented primarily in **C++** while preparing for software engineering interviews and strengthening my understanding of Data Structures and Algorithms.

## About

This repository serves as a personal archive of my coding practice and progress. Rather than simply collecting accepted solutions, I use it to:

- Improve problem-solving skills
- Master fundamental data structures and algorithms
- Practice writing clean and efficient C++ code
- Build strong interview preparation habits
- Revisit problems and optimize earlier solutions

Most solutions are written in **Modern C++**, with an emphasis on readability, correctness, and time-space complexity.

## Topics Covered

The repository includes problems across a wide range of interview topics, including:

- Arrays & Hashing
- Two Pointers
- Sliding Window
- Stack & Queue
- Binary Search
- Linked Lists
- Trees & Binary Trees
- Tries
- Heap / Priority Queue
- Backtracking
- Graphs
- Dynamic Programming
- Greedy Algorithms
- Bit Manipulation
- Intervals
- Math & Geometry

More topics will be added as I continue solving problems.
